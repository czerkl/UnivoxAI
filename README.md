# UnivoxAI v6.2 SE(Special Edition)

**UnivoxAI** — это высокопроизводительный Telegram-ассистент, оптимизированный для работы с последним поколением моделей Google Gemini (v3 Flash). Сборка v6.2 переработана для обеспечения максимальной стабильности, профессионального форматирования и интеллектуального взаимодействия.

## 🚀 Ключевые фичи (All-in-One)
* **Expert System Prompt:** ИИ настроен как профессиональный справочник. Использует структурированные списки (★), эмодзи и четкий технический стиль.
* **Smart Formatting:** Автоматическая поддержка Markdown и блоков кода. Внедрена система **Fallback**: если ИИ присылает битую разметку, бот автоматически исправляет её или отправляет текст без ошибок.
* **Performance Tracking:** Замер скорости генерации ответа в секундах (⏱).
* **Model Hot-Swap:** Мгновенное переключение между моделями (`gemini-3-flash-preview`, `gemini-2.5-flash-lite` и др.) без перезагрузки бота.
* **Render Optimized:** Архитектура с приоритетным запуском веб-сервера. Гарантирует прохождение Health Check и защиту от «засыпания» сервиса.
* **Safety Limits:** Жесткий контроль длины ответа (до 3500 символов) на уровне системной инструкции для предотвращения ошибок Telegram API.

## 🛠 Технический стек
* **Core:** Python 3.10+
* **Framework:** Aiogram 3.17.0 (Async)
* **AI Engine:** Google GenAI SDK v0.3.0
* **Server:** Aiohttp (Port: 10000)
* **Deployment:** Optimized for Render.com

## 🕹 Команды
* `/start` — Запуск ассистента и проверка статуса системы.
* `/change <model_name>` — Переключение на другую модель Gemini.
* `/info` — Вывод технической сводки о версии и платформе.
* `Текстовые сообщения` — Прямое общение с ИИ.

## ⚙️ Быстрый запуск (Deployment)
1.  **GitHub:** Загрузите файлы `main.py`, `requirements.txt` и `render.yaml`.
2.  **Render:** Создайте новый Web Service, подключив репозиторий.
3.  **Env Variables:**
    * `BOT_TOKEN`: Токен от BotFather.
    * `GEMINI_API_KEY`: API ключ из Google AI Studio.
    * `PORT`: 10000 (стандарт для Render).
