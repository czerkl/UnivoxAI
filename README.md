# UnivoxAI v6.1

Легкий и быстрый ассистент для Telegram, работающий на базе последнего поколения моделей Google Gemini. Проект оптимизирован для работы в облачной среде (Render) и обеспечивает стабильное взаимодействие без лишних функций.

## 🚀 Основные возможности
* **Умные ответы:** Использование модели `gemini-3-flash-preview` по умолчанию.
* **Авто-нарезка:** Бот автоматически разбивает длинные ответы (более 4000 символов) на несколько сообщений.
* **Смена моделей:** Возможность переключения на любую доступную модель Gemini через команду `/change`.
* **Render-Ready:** Встроенный веб-сервер для обработки внешних пингов, предотвращающий засыпание сервиса.
* **Форматирование:** Поддержка Markdown для читаемых и структурированных ответов от ИИ.

## 🛠 Технологический стек
* **Язык:** Python 3.10+
* **Фреймворк:** aiogram 3.x
* **ИИ Движок:** Google Generative AI SDK (v0.3.0)
* **Сервер:** aiohttp

## ⚙️ Установка и запуск
1. Склонируйте репозиторий.
2. Создайте файл `.env` и добавьте туда:
   ```env
   BOT_TOKEN=ваш_токен_телеграм
   GEMINI_API_KEY=ваш_ключ_gemini
   PORT=10000
3. Установите зависимости: pip install -r requirements.txt.
4. Запустите бота: python main.py.
